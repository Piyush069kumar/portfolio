# Piyush Kumar - Portfolio

A professional, fully responsive, and highly interactive developer portfolio showcasing my experience, projects, skills, and education. Designed with a premium "Obsidian Editorial" aesthetic, featuring smooth scrolling and entrance animations.

## 🚀 Features

- **Custom Design System**: Built with clean, semantic Vanilla CSS (no heavy CSS frameworks).
- **Smooth Animations**: Powered by [GSAP (GreenSock)](https://gsap.com/) and [Lenis](https://lenis.studiofreight.com/) for buttery-smooth entrance animations and scroll experiences.
- **Dynamic Projects Grid**: Features an asymmetric masonry-style layout for selected projects.
- **Fully Working Contact Form**: Integrated with [Formspree](https://formspree.io/) for seamless AJAX email submission without page reloads.
- **Responsive Layout**: Optimized for both mobile devices and large desktop monitors.

## 🛠️ Tech Stack

- HTML5 (Semantic Markup)
- Vanilla CSS3 (Custom Variables, Flexbox, Grid)
- Vanilla JavaScript
- GSAP 3.12 (ScrollTrigger)
- Lenis (Smooth Scroll)
- Formspree (Form Handling)

## 💻 Getting Started

This project is completely static and requires no build steps or local servers to view. 

1. Clone this repository:
   ```bash
   git clone https://github.com/Piyush069kumar/portfolio.git
   ```
2. Navigate into the directory:
   ```bash
   cd portfolio
   ```
3. Double click on `index.html` to open it in your favorite web browser!
